# v1.2.16 ? Pinterest-style project indexes

Prepared 5 November 2026 for staging only.

## Fixed
All five project indexes now pack natural-height cards using grid masonry,
instead of leaving the entire row as tall as its tallest card. This applies to
Temple Architecture, Portrait, Murals, Monumental and Other Installations.
Collectables already uses masonry and is unchanged. Titles, scales, rounded
images, page gutters and links into project galleries are preserved.

Packing recalculates with ResizeObserver after card/image dimensions change,
after fonts load and on viewport resizing. Mobile retains a single column;
one/two-project layouts retain their existing centred presentation.

## Validation
Astro build and catalogue checks passed before release preparation. Release
build, version tests and GitHub CI must pass before merge/publication.

## Rollout and rollback
Target develop only. Publish a prerelease at the exact merged commit, never
reuse v1.2.15. The user accepted Cloudflare failures as non-blocking for staging;
live deployment verification is separate from release publication.
Production main and FREEZE (2026-11-07) remain unchanged.
Rollback through a revert PR to develop; previous staging tag is v1.2.15.
