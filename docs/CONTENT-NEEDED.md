# Content the studio holds and the site does not

Phase 5 of the staging plan. Everything below is a blank the site cannot fill
for itself — no year, client, sitter or measurement is inferred or guessed
anywhere in this repository, and none should be.

Fill a cell in and it appears on the site with no code change. Leave it blank
and the site stays silent about it rather than inventing something.

## 6. Is "Shekon" spelt correctly?

A seven-foot figure installed at an Air Force camp in Hyderabad, appearing
across four photographs and in the page title, the URL `/portraits/shekon` and
four alt descriptions. It does not read like a name in any of the languages the
rest of the archive uses, and it may be a transcription slip from the profile
deck. If it is wrong, say what it should be and the slug changes with it.

## What happens when you fill these in

| Field | Where it appears |
| --- | --- |
| `scale` | Collection tiles and the project's fact list, as Scale |
| `form` | The same places, as Form — already live |
| `year` | The project's fact list, as Year — and the homepage's "Selected works" line, which derives its range from the earliest and latest year recorded rather than a typed one |
| `client` | The project's fact list, as Client — only for the ones you mark nameable |
| `description` | The project page and the collection tile, as it does now |

Nothing here blocks a release. The site is accurate about what it knows; these
are the things it does not know, stated plainly rather than filled with
plausible guesses.
